# Design system — Light Atelier

## Direction
Light, airy portfolio AI surface. Soft warm off-white ground, ink type, coral CTAs. Brand name dominant; image is a rounded visual panel (not a dark full-screen takeover).

## Tokens
| Token | Value | Role |
|---|---|---|
| `--bg` | `#f7f5f2` | Page ground |
| `--panel` | `#ffffff` | Surfaces |
| `--ink` | `#16151a` | Primary type |
| `--muted` | `#6f6a75` | Secondary type |
| `--coral` | `#e85a3a` | Primary CTA |

## Proportions
- Header: 68px
- Buttons: min-height 48px, pill radius
- Hero: ~52/48 split on desktop with generous padding
- Chat column: max 720px centered
- Panels: 20px radius, soft shadow

## Motion
Hero fade/slide, CTA lift, chat/JD crossfade. Respects reduced motion.
